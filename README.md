# 三羊开泰 🐑

一款「羊了个羊」式的卡牌消除小游戏。纯原生 **HTML + CSS + JavaScript**，单文件、零依赖、移动端适配。

## 🎮 在线试玩

👉 **https://maybe112358.github.io/san-yang-kai-tai/**

## 玩法

- 屏幕上方是多层堆叠的卡牌，只能点击**最上层没有被遮挡**的牌。
- 点击后卡牌飞入下方 **7 个槽位**。
- 任意时刻槽里出现 **3 个相同图标**即自动消除。
- **全部消除**即通关；**7 个槽位占满且无法消除**即失败。

## 功能

- 🃏 多层 3D 堆叠视觉（层叠阴影、高度差、遮罩渐显）
- ✈️ 丝滑动画：飞牌落地、FLIP 平滑补位、粒子消除特效
- 🎚️ 4 个关卡，难度递增（JSON 配置，易扩展）
- 🧰 道具系统：提示 💡 / 撤回 ↩️ / 洗牌 🔀 / 移出 💣（模拟看广告获得）
- 🔊 WebAudio 音效（可静音）
- ⏱️ 计时器 + 步数统计
- 💾 进度保存（localStorage）
- 📱 触屏友好，响应式缩放

## 本地运行

直接用浏览器打开 `index.html` 即可；或起一个静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 技术栈

纯原生，无任何框架。DOM + CSS Transform 实现堆叠与动画。
